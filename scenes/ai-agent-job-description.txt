# hook
You'd never hire someone without a job description. So don't do it to an A-I.

# bad
Most people set up an A-I agent like this. Here's everything. Go help.

# risk
That's a new hire with every key to the building, and no instructions.

# j1
Line one. What's the job? One job. Answer new leads. Not, run my business.

# j2
Line two. What can it touch? The calendar, yes. The bank account, no.

# j3
Line three. What must it never do? No refunds. No made-up prices. No medical advice.

# j4
Line four. Who does it ask? When it isn't sure, it hands off to a person. By name.

# sim
Watch a demo. A customer asks for a discount. That's not in the job.

# sim2
So the agent doesn't guess. It says, let me get the owner, and passes it on.

# review
And like any new hire, check its work. Read its conversations in the first week.

# verdict
A good agent isn't the smartest one. It's the one that knows its job.

# cta
Follow for one business fix every week.
